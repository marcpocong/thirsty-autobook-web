## Changes

- `availability-contract.ts` centralizes the observed endpoint/query and evidence/failure classifications. Active browser reads keep their existing genuine helper. The query now requests the observed membership-access metadata. Empty metadata is supported; nonempty or malformed membership metadata fails closed because guest eligibility semantics have not been qualified. Legacy snapshots without the optional field retain strict existing validation.
- Existing error codes remain compatible, with separate classifications for auth, denial, throttle, unsupported endpoint, incompatible response, stale evidence, transport failure and unknown evidence. Server cache age and STALE responses cannot become fresh merely because they arrived now. Failure bodies are released before returning errors.
- The observer and Network Readiness stop an action on its first 401/403/429. The observer preserves refusal status and marks later local refusals NOT SENT. Ordinary bounded transport/5xx backoff remains separate. Network diagnostics distinguish requested reads from actual attempted reads.
- The availability checker displays scoped failure classifications while all affected cells stay UNKNOWN. No new source is guessed and no denial turns into an empty/open grid.
- A complete validated closed Mango template received sufficiently before its authorized release is UNRELEASED even if `dates:true`. Partial, failed, contradictory or boundary-time evidence cannot acquire that inference. Explicit open cells are not hidden. Current Available Now discovery still requires actual open, priced, complete target hours.
- Pre-release evidence retains actual failures. Production records and stops an applicable auth/access/throttle/schema restriction, including a denial delivered after the bounded freeze waiter expires. The existing abort path prevents further unsent dispatches and preserves in-flight ambiguity. This does not waive identity, security, price, clock, journal, overlap or permit checks.
- The isolated observer's close operation is idempotent. An exit already observed before the CDP close reply cannot cause a second five-second event wait; listeners and timeout handles are removed. Spawn and process-close failures have explicit codes. These are supported cleanup defects, not proof of the historical native abort's cause.
