# September 26 release evidence archive

This archive separates two reports by author. `codex/REPORT.md` and its supporting logs are OpenAI Codex's analysis of the September 26 run. `claude/SERVER_ARBITRATION_INVESTIGATION.md` is Claude's separate investigation of the September 25 release; it is not a report about the September 26 run. Claude's supporting September 25 evidence remains in [diagnostics-archive/2026-09-25](../2026-09-25/).

Logs are sanitized for publication. Raw private checkout response bodies, journals, profiles, credentials, customer/contact fields, local user paths, locks, and runtime state are excluded. JSON and NDJSON fields matching the exporter's sensitive-key rules are redacted.
